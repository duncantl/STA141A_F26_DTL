
# How to answer the questions

+ Use your common sense, intuition, contextual knowledge and insights
  about the question.

+ Clarify how you interpret the question
  + Make sense of the variables
  + Identify ambiguities
  + Say how you interpret these
  + Say how you can quantify the question
  + Show the R code
  + Show the results
  + Provide an interpration of the results
     + Don't just show the results with no conclusion.

+ Include the code that explains what you did
  + Not all the code you executed that is not relevant.

+ Do **NOT** include numerous pages of computer output
  + Summarize appropriately.
  
+ Make certain to indicate where you got help and used code from other sources.

+ Cite your sources for any ideas or code you used.
